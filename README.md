# Sonic Unleashed Recompiled × Archipelago

Archipelago Multiworld integration for Sonic Unleashed Recompiled.

> **Work in progress.** No game files are distributed here.

## Development Process & AI Assistance

This Archipelago integration was developed by ZMGBZak with the assistance of AI tools, primarily used to understand the existing codebase, investigate game functions through Ghidra, troubleshoot issues, and explore possible implementations.

AI-assisted code and suggestions were reviewed, compiled, and tested in-game by the developer at each stage before being approved and integrated.

The initial development period involved approximately **14 hours of work per day over two weeks**, dedicated to reverse-engineering research, implementation, debugging, and extensive gameplay testing.

AI served as a development and research assistant, while the developer remained responsible for testing, evaluating, and approving the changes.

## Distribution policy

- Never upload game dumps, extracted archives, or proprietary Sonic Unleashed models, textures, audio, or videos.
- Never upload credentials, private configuration, or debug logs.
- Distribute only code and original resources you have rights to share, while respecting upstream licenses.
- Review compiled client binaries and every bundled resource before publishing a GitHub Release. A local build is not automatically redistributable.
- Players must obtain their own lawful copy of the game and follow upstream installation instructions.

## Planned updates

- **Client:** versioned GitHub Releases with a separate updater, replacing selected files after the game exits.
- **APWorld:** separate release artifact and a notification in the client when a newer APWorld is needed.

No public release is available yet.
